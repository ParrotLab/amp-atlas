Onboarding Checklist

Week 1

Day 1-2: Setup

  • Set up development environment
  • Complete security training
  • Set up Claude Code workspace
  • Install recommended VS Code extensions
  • Meet with team leads
  • Review company playbooks

Day 3-5: Training

  • Complete AI operations overview
  • Review domain workspace structure and learn the Draft → Review → Publish workflow
  • Shadow team member on active project
  • Complete first practice draft submission

Week 2

Day 6-8: Integration

  • Begin contributing to assigned system
  • Set up recurring 1:1 with system mentor
  • Submit first review request
  • Complete onboarding retrospective and share feedback
