# User-guide screenshots

Drop screenshot files here. Guides reference them with a relative path of
`../images/<name>.png` (every guide lives one folder deep, so this path works from all of
them).

**Convention:** lowercase, hyphenated, `.png`, descriptive name matching the list below.
Capture on macOS at a consistent window size; crop tight to the relevant UI.

> Note: these relative paths are intent markers for the repo copy. When pasting a guide into
> Notion, upload the matching image inline at the same spot.
