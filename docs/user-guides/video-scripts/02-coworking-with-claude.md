# Video 2 — Coworking with Claude on a new project

**Format:** Loom screen-share of AMP Atlas (plus your Claude window)
**Length:** ~5 min
**Goal:** Viewer understands that Claude works in the System's files outside AMP Atlas, that
its work should live in a Draft, and how to refine it in AMP Atlas and hand it off to review.

---

## Before you record

- 💡 Have a System open and be ready to **create a Draft** for a believable demo project.
- 💡 Have your Claude tool ready in another window — the **Claude app** or **Claude Code** —
  already pointed at that System's folder.
- 💡 Pre-plan a small, real-feeling ask for Claude (e.g. "draft a pitch and braindump for an
  onboarding-email refresh") so the on-camera result is quick and clean.
- 💡 Decide how much of Claude's actual working you'll show vs. cut to the finished files.

---

## The script

### 0. Cold open ⏱️ ~20s
**🖱️ On screen:** AMP Atlas open on a System.
**🎙️ Say:** "In this video I'll show you how to team up with Claude on a new project — Claude
drafts the first version, and you review and refine it right here in AMP Atlas. The nice part
is you and Claude are working on the exact same files, so there's no mystery about what it did."

### 1. The big idea ⏱️ ~30s
**🖱️ On screen:** Gesture at the file tree / editor.
**🎙️ Say:** "Quick mental model: Claude does its work in your System's folder using its own
app — that's *outside* AMP Atlas. And because AMP Atlas is a live window into that same
folder, whatever Claude writes just shows up here automatically. Think of AMP Atlas as where
you *see and shape* the work, not where Claude runs."

### 2. Set up a Draft first ⏱️ ~40s
**🖱️ On screen:**
- Open the version switcher in the status bar.
- Create a **new Draft**; give it a clear name (e.g. "Onboarding email refresh").
- Point out you're now in that Draft (status bar).

**🎙️ Say:** "Before I bring Claude in, I'll set up a **Draft** — my private, safe workspace.
I'll open the version switcher up here, create a new Draft, and name it for the project. Now
anything that happens lands in this Draft, safely away from the official Live Version, until
it's been reviewed."

### 3. Hand the work to Claude ⏱️ ~60s
**🖱️ On screen:**
- Switch to your Claude window.
- Type (or show) your ask, e.g. "Help me start a project to refresh our onboarding emails —
  draft a braindump and a pitch."
- Let it work (or cut ahead).

**🎙️ Say:** "Now I'll hop over to Claude — this is the Claude app, working in the same System
folder. I'll describe what I want: help me start this project, draft a braindump and a pitch.
And I'll let it go to work. You can go back and forth here as much as you like — this is just
a normal conversation."

**💡 Tip:** If Claude's run is slow, stop the recording and resume once the files exist, or
speed this section up in editing.

### 4. See it appear in AMP Atlas ⏱️ ~45s
**🖱️ On screen:**
- Switch back to AMP Atlas.
- Show the new files appearing in the Draft's file tree; open one (e.g. the pitch).

**🎙️ Say:** "Back in AMP Atlas — and there it is. The files Claude created just showed up in
my Draft. I'll open the pitch… and I can read exactly what it drafted, in a clean, friendly
editor. No copying and pasting, no exporting — it's just here."

### 5. Refine together ⏱️ ~50s
**🖱️ On screen:**
- Make a small edit directly in the editor.
- Mention you could also go back to Claude for bigger changes.
- Save (⌘S).

**🎙️ Say:** "From here I refine. I can edit directly — let me tweak this line — or I can go
back to Claude and ask for a bigger change, and it'll update the files again. I'll save as I
go. The key thing is *my* judgment shapes the final result — Claude gives me a strong first
draft, and I make sure it actually fits how we work."

### 6. Hand off to review (tease) ⏱️ ~25s
**🖱️ On screen:** Point at the Save / Submit-for-review control; don't complete it.
**🎙️ Say:** "Once I'm happy, this goes through the exact same review as anything else — I'd
submit it for a teammate to check before it becomes official. I cover that in the 'submitting
your work for review' video."

### 7. Wrap ⏱️ ~15s
**🖱️ On screen:** Rest on the Draft.
**🎙️ Say:** "So that's coworking with Claude: set up a Draft, let Claude draft, and refine it
here. Give it a try on your next project. Thanks for watching!"

---

## If something goes wrong while recording

- **Files don't appear right away** — click around the tree or reopen the folder; AMP Atlas
  picks up on-disk changes, but give it a beat.
- **Claude edits the wrong spot** — that's fine to show briefly, then correct it; it reinforces
  that *you're* in control. Or cut to the good state.
- **You accidentally started on the Live Version** — point out you'd move those changes into a
  Draft, then do it, so the "keep it in a Draft" message stays true.
