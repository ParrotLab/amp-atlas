# AMP Atlas — Loom video scripts

Screen-share walkthrough scripts for the AMP Atlas tutorial videos. Each file is one Loom.
You share your screen (the AMP Atlas app), read the **🎙️ Say** lines in your own voice, and
do the **🖱️ On screen** actions as you go.

## How to use a script

- **🎙️ Say** = your narration. It's a starting point, not a teleprompter — say it your way.
- **🖱️ On screen** = the action to take or thing to point at while you talk.
- Beats are small on purpose. Pause, re-do, and re-record a beat whenever you fumble — Loom
  makes trimming easy.

## Before you record (every video)

- **Keep it short.** Aim for **3–5 minutes**. If a video wants to run long, it's probably two
  videos.
- **Set up clean demo data.** Have a demo System (or two) already connected, with a couple of
  believable documents. Nothing confidential on screen.
- **Tidy your screen.** Hide personal bookmarks, notifications, other repos/windows, and
  anything with private info (tokens, client names, emails).
- **Size the window** consistently so all videos match.
- **Talk like a person.** Warm and plain. You're showing a colleague around, not reading a
  manual.

## Keep the language accurate (and jargon-free)

Use AMP Atlas words, never git ones. Say **Draft, Save, Submit for review, Approve, Publish,
Live Version, System** — never branch, commit, push, merge, or PR.

A few things that are easy to get wrong on camera — keep the narration honest to what the app
actually does today:

- **You connect Systems, you don't build them.** "Adding a System" points AMP Atlas at a folder
  that already exists — the app doesn't create the folder structure from scratch.
- **A review is one note + a decision.** There are no per-line comments and no comment labels
  in the app — you type one note and choose **Approve** or **Request changes**.
- **Approve is a sign-off, not publishing.** After approval, the *author* publishes from the
  Inbox as a separate step.
- **Drafts start from the Live Version** — you can't branch a Draft off another Draft yet.
- **Claude runs outside AMP Atlas** (the Claude app or Claude Code); AMP Atlas shows you the
  files Claude changes on disk.
